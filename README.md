# Weather Dashboard Application

## Project Overview
The Weather Dashboard is a web application designed to provide users with real-time weather metrics, multi-day forecasts, and severe weather alerts based on geographic location. This tool solves the hassle of navigating overly cluttered weather sites by delivering an intuitive, fast, and responsive summary of current conditions.
